## Remediation

- **Первопричина:** прежний Result-only script не создавал declarations. Новые проверяемые runtime consumers импортируют публичный пакет, которому нужны собранные declarations. Предварительно выполненный build скрыл зависимость в первой локальной проверке.
- **Воспроизведение:** архив точного `cfd3f5a` без ignored artifacts и `.env`, с доступом к тем же установленным инструментам через symlink `node_modules`. `pnpm --filter @polyphony/core-types typecheck` завершился с exit 1: пять TS2307 в example, import-smoke, M1 и parser tests.
- **Исправление:** только script `typecheck`: `pnpm run build && tsc --project tsconfig.tools.json`. Публичные импорты сохраняются; source, контракт, зависимости и lockfile не меняются.
- **Прямой blast radius:** порядок package/root/CI проверок, этот отчёт и [implementation evidence](gh-45.t1.implementation.md).
- **Доказательство исправления:** в том же чистом архиве заменён только `package.json`; та же команда прошла с exit 0 без предварительного build. Логи координатора: `/tmp/yaagi-core-types-cp2/clean-before.log` и `clean-after.log`. Повторные полные root gates фиксируются в implementation evidence; эти временные логи не заменяют независимый delta-аудит.
