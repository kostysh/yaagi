## Результат и ограничения

Собранный публичный `@polyphony/core-types` предоставляет семь parsers: три ID, opaque revision, evidence reference и два вида времени. Допустимые значения сохраняются точно; неправильный вход даёт только `invalid_input`. Result/error/ref объекты parsers frozen, ref копируется. Исходный generic `Result<T, E>` не изменён. Production source — один import-free файл, без dependencies, I/O или clock; нового production-порта/validator framework нет.

Это наблюдаемое поведение проверки общих значений, не реализация timeline или I1. Fixtures синтетические. Brands/parsing не устанавливают принадлежность ID, существование/истинность evidence, freshness, полномочия или snapshot mapping. Хранения, миграций, транзакций, model calls и действий здесь нет; реальные #47/#49/#50 и E3 не закрыты. Произвольный JavaScript/скомпрометированный процесс не считаются изолированными.

## Evidence требований

| Контур | Наблюдение |
| --- | --- |
| CT-R1/R2: production parsers | Непустые точные строки/ref; допустимые wall/elapsed. Отказ для пустого token, missing/null/лишних/symbol полей, arrays/class instances/accessors, дробей/NaN/infinity/unsafe integers, coercible/boxed values и отрицательного elapsed |
| CT-R3: точность | Сохраняются пробелы, регистр, Unicode forms, signed zero и safe-integer endpoints; wall time может идти назад независимо от elapsed |
| CT-R4 и прежний Result | Positive/negative compile-time fixtures через public export: ID/revision brands и оба time brands не смешиваются; raw primitives не присваиваются. Прежние Result fixtures, narrowing/generics/falsy/undefined/readonly сохранены без изменений |
| CT-R5/R6: immutability | Frozen/null-prototype/non-enumerable data records; входные descriptors неизменны. Поздняя мутация caller record не меняет прежний result; Result/error/ref frozen, попытки изменения отклоняются |
| CT-R7: безопасный отказ | Accessors не вызываются; throwing reflection и revoked proxy дают точный bounded failure без canary input/message/stack. Исправленный следующий вход проходит |
| CT-R8: граница | Прежние manifest/dependency/root-export ограничения сохранены; отрицательные ESLint probes запрещают Node/relative/private/dynamic imports и re-export. ESM smoke проверяет точные семь runtime exports и отсутствие исходящих imports |
| CT-R8: sampled effects | Отдельный fresh Node-процесс импортирует production entry и вызывает каждый parser с допустимым/недопустимым входом. Timer/network globals, console и `Date.now` запрещены; счётчик попыток остаётся нулевым, global keys неизменны. Это sampled probe плюс static/source review, не OS sandbox |
| M1 | Один неизменный T1-shaped consumer, production API и ограниченный test-only fixture double: успех, отказ elapsed/ref и повтор с исправленным входом. Double не вызывает production parsers и не заменяет полные production negative tests; это не сохранение TickFrame в БД |
| Guide | [examples/usage.ts](../../../packages/core-types/examples/usage.ts) исполняется через публичный собранный export: success, `invalid_input`, corrected elapsed. Assertions проверяют данные; [guide](../../../packages/core-types/docs/usage.md) содержит точные команды |

`tsconfig.test.json` сохраняет `types: []` для Result/brand contract fixtures. Node runtime tests/scripts/example проверяются отдельным `tsconfig.tools.json`; production source сохраняет `types: []`. Обе конфигурации проверяют нужные файлы, type stripping не заменяет compiler checks.
