- Общий commit/snapshot/rollback: architecture:349–355; spec R1–R9, AC1.
- Domain schemas/DTO/transforms/retrieval остаются у владельцев: architecture:81,185,403–405; ADR-002:22–26; spec:18,28.
- Lifecycle lock не заменяет внешнее effect fencing: architecture:372–383; R13–R14, AC3.
- Common contracts отделены от SQL/native/Node: ADR-001:20,26,48; spec:24–30, R19, AC4.
- Signatures, migration/cancel semantics и binding остаются решениями CP1: spec:26,59,94–96.

Не подтверждены runtime/API/native/ABI, спайки, memory/RAG, queue, I1/E3, аппаратный power-loss/restart и другие платформы. Security проверяется отдельно.
