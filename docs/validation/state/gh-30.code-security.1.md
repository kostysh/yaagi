Close первого снимает lock активной второй connection. Противоречит сохранению native locks (ADR-002:61), но corruption или обход WAL writer exclusion этим witness не доказаны |

Независимый witness: A остановлен перед настоящим close созданного fd; B через public API открывает тот же файл, мигрирует и удерживает write callback. До close A `/proc/locks` содержит DB READ lock, после close — нет. Файлы не подменяются; вредоносный SQL не используется. Внешний writer всё ещё получил SQLITE_BUSY, B committed и readback корректен: это ограничивает impact, но не устраняет снятие native lock. [SQLite о стороннем close](https://www.sqlite.org/howtocorrupt.html#posix_advisory_locks_canceled_by_a_separate_thread_doing_close).

## Remediation

- Первопричина: «новый inode при open» ошибочно считался «inode ещё не используется SQLite при close»; publication и close разделены достижимым interleaving.
- Коррекция: закрыть private temporary inode до atomic no-replace публикации конечного pathname; выигравший другой creator допустим. Не добавлять app lock/queue/retry.
- Прямой blast radius: первая подготовка DB и cleanup временного файла; private permissions, обязательная DB и отсутствие постороннего close на уже открытой DB сохраняются.
- Regression: тот же public first-create interleaving, native lock должен сохраниться после close A; отдельные commit/readback/cleanup assertions. Только отсутствие corruption не закрывает finding.
- Исправлено: закрытый 0600 inode из private temporary directory публикуется `linkSync` без замены конечного файла. При EEXIST проверяется файл победившего creator; temporary directory очищается в finally. Обычное открытие существующей DB выполняет только metadata checks.
- Проверка: сохранённый public regression на c3cee31 dist → FAIL (DB lock исчезает); с исправлением → PASS (lock остаётся, commit/reopen корректны, temp artifacts не остаются, mode 0600). State format/lint/typecheck/build и root format:check/test/diff check PASS; **51/51 tests**, без skipped.
- Статус remediation: `verified` локально; независимый delta verdict ожидается. Исходный FAIL сохраняется.
