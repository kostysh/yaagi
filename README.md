# Yaagi

Yaagi — репозиторий разработки «Полифонии»: долгоживущего цифрового организма, который сохраняет единство личности и непрерывность во времени, опирается прежде всего на локальные когнитивные модели и развивается через управляемые обратимые изменения.

Проект перезапущен. Техническая архитектура и новая реализация ещё не определены; текущее состояние содержит концепцию и правила дальнейшей разработки. Предыдущая реализация сохранена в теге `v0-archived`.

## Разработка

Основная ветка интеграции — `develop`. Работа выполняется в отдельных task-worktree и task-ветках через Pull Request. Актуальные правила и команды находятся в [методологии разработки](docs/development-methodology/README.md).

README намеренно не фиксирует стек, архитектуру или команды запуска до появления соответствующих утверждённых документов и реализации.
